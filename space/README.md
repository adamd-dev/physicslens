# PhysicsLens

Film a ball drop, a throw or a pendulum. PhysicsLens tracks the ball (motion and colour trackers, or Meta SAM 3.1),
fits the physics with SciPy, and a Meta Muse Spark agent checks the fit before you see a number.

This Space is a **public demo**: every uploaded video, its file name and its result are visible to all visitors in
History, and the disk is cleared when the Space restarts. Source code: https://github.com/adamd-dev/physicslens
